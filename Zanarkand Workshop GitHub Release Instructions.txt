ZANARKAND WORKSHOP v0.4.0 - GITHUB RELEASE
==========================================

1. Confirm the Release build and smoke tests pass.
2. Commit the intended v0.4.0 files and push them to main.
3. Confirm the GitHub Actions Build workflow passes.
4. Create and push the release tag:

   git tag -a v0.4.0 -m "Zanarkand Workshop v0.4.0"
   git push origin v0.4.0

5. Create a draft release using RELEASE_NOTES_v0.4.0.md.
6. Upload only ZanarkandWorkshop-v0.4.0-win-x64.zip.
7. Download and test the ZIP from a clean folder.
8. Confirm v0.4.0 is displayed and open a test master project.
9. Publish the release after the packaged application passes testing.

Do not recreate or move the tag after publishing. If a final fix is required
before publication, correct the main branch and create a new release as needed.
